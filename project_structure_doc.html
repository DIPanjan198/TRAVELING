1. High-Level System Architecture

AeroTravel is built using a modern decoupled Client-Server (Monorepo) Architecture designed for high performance, real-time interactivity, and responsive glassmorphic aesthetics.

Frontend Client Layer

Framework: React 19 & React Router DOM v7

Styling: Modular CSS3 Design System with Cyberpunk Glassmorphism & Theme Customizer Engine

Real-Time: Socket.IO Client for instant direct messaging & notifications

Backend REST & Socket Server

Runtime: Node.js & Express.js

Database: MongoDB & Mongoose ODM

Authentication: BcryptJS password hashing & session management

4. Backend API & Real-Time Socket Architecture

HTTP REST Endpoints

Method Endpoint Description
POST /api/auth/register Registers new user account with destination, budget range, and travel style preferences.
POST /api/auth/login Authenticates user credentials against bcrypt-hashed passwords.
GET /api/users Returns list of registered travelers for destination matching and chat discovery.
GET /api/messages/:user1Id/:user2Id Fetches persistent message conversation history between two users.

Socket.IO Real-Time Events

  • registerUser (userId) — Binds Socket ID to logged-in User ID for active routing.
  • sendMessage ({ senderId, receiverId, text }) — Persists message and delivers real-time payload.
  • newMessageNotification — Triggers audio chime and floating toast badge for receiver.

5. UI/UX Design System & Customization Engine

The application features a modern Cyberpunk Glassmorphism Design System built with CSS custom variables:

  • Color Palettes: Cyberpunk Indigo (`#6366f1`), Sunset Volcano (`#f43f5e`), Forest Emerald (`#10b981`), Cosmic Nebula (`#a855f7`).
  • High-Contrast Select Styling: Custom `#0f172a` option popovers to guarantee 100% text legibility across all themes and operating systems.
  • Typography: Google Fonts Outfit (headings) and Plus Jakarta Sans (body & controls).
